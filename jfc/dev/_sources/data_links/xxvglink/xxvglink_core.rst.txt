Overview
========

`xxvglink_core` manages one or more **GTY** transceivers on UltraScale+ for 25G serial links. It handles QPLL clocking, per-channel resets, 64B/66B block synchronization, scrambling/descrambling, and exposes raw 64-bit TX/RX data buses to the user logic. It also provides a **BSB** register interface to monitor and control the transceivers from software.

.. autoentity:: xxvglink_core

Parameters
==========

- **LINK_TO_QUAD_MAP:** Maps each GTY link index to its quad number (0 … N−1). Determines which QPLL instance clocks each channel.

- **QUAD_TO_REFCLK_MAP:** Maps each quad to one of the ``NUMBER_OF_REFCLK`` external 156.25 MHz differential reference clocks.

- **USED_LINKS:** List of link indices that carry actual traffic. Links not listed are stripped of scrambling, descrambling, and block-sync logic to save resources.

- **IMPLEMENT_TX / IMPLEMENT_RX:** Enable the transmit or receive path, respectively. Allows TX-only or RX-only instantiations.

- **DONT_RESET_ON_DATA_ERROR_IN:** When ``'1'``, a data error from the GTY does not trigger an automatic reset of the receive path.

- **NUMBER_OF_CONTROL_BYTES / NUMBER_OF_STATUS_BYTES:** Number of additional control/status bytes appended after the built-in common BSB registers, exported to the parent (`xxvglink_array`) for its own BSB handling.

- **EXAMPLE_SIMULATION / EXAMPLE_SIM_GTRESET_SPEEDUP:** Simulation parameters forwarded to the Xilinx GTY SecureIP model for faster reset in simulation.

- **SIM:** When ``TRUE``, enables simulation-friendly elaboration.

- **NUMBER_OF_REFCLK / NUMBER_OF_RX_LINKS / NUMBER_OF_TX_LINKS / NUMBER_OF_LINKS:** Derived from the map generics. Do not override.

Interface
=========

SerDes
------

- ``tx_p`` / ``tx_n``: Differential serial outputs, one per GTY link.

- ``rx_p`` / ``rx_n``: Differential serial inputs, one per GTY link.

- ``refclk_p`` / ``refclk_n``: **156.25 MHz** differential reference clocks (one per reference index).

- ``refclk_div2``: Per-reference toggle at half the reference clock frequency, for monitoring.

- ``txclk_div2``: Toggle at half the TX word clock frequency, for monitoring.

TX datapath
-----------

- ``tx_data``: Array of 64-bit words to transmit, one per TX link. The most-significant byte is transmitted first.

- ``tx_header``: 2-bit 64B/66B block header per TX link: ``01`` for data, ``10`` for control/ordered-set.

- ``tx_ready``: Per-link signal indicating that the GTY gearbox will accept the current word. Low for 2 out of every 66 cycles (overhead bits).

- ``tx_clk``: TX word clock output generated by the GTY MMCM (~402.8 MHz at 25 Gbps).

- ``tx_resetdone``: Per-link flag, high when the TX path has completed reset and is ready.

RX datapath
-----------

- ``rx_data``: Array of 64-bit received words, one per RX link.

- ``rx_data_valid``: Per-link valid flag for ``rx_data``.

- ``rx_header``: 2-bit 64B/66B block header per RX link.

- ``rx_header_valid``: Per-link valid flag for ``rx_header``.

- ``rx_clk``: Per-link recovered RX word clock.

- ``rx_resetdone``: Per-link flag, high when the RX path has completed reset and block lock has been acquired.

Control and status
------------------

- ``stable_clk``: Free-running stable clock (typically ``bsb_clk``) for the GTY reset state machines.

- ``control_bytes``: Additional control byte array exported to the parent for BSB decoding.

- ``status_bytes``: Additional status byte array provided by the parent to be packed into BSB replies.

- ``s_axis_bsb_t*`` / ``m_axis_bsb_t*`` on ``bsb_clk`` / ``bsb_rst``: Byte-serial BSB command/reply interface for register access.

- ``areset``: Asynchronous active-high reset.

Implementation details
======================

Principle of operations
-----------------------

`xxvglink_core` instantiates one Xilinx **GTYUWIZARD** IP block per quad for QPLL and lane instantiation, a per-lane **GTY TX/RX reset** finite-state machine, and per-link `xxvglink_block_sync`, `xxvglink_scrambler`, and `xxvglink_descrambler` modules (for used links only). The GTY produces and consumes 64-bit words at the TX word clock rate; the 64B/66B gearbox overhead is exposed through the ``tx_ready`` signal.

The BSB register interface provides a common register map (GTY status, reset control, link lock flags) plus the user-supplied additional bytes. Software reads per-link lock status, per-quad QPLL lock, and TX/RX reset-done flags through BSB status bytes.
