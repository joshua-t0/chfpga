.. title:: Data Links

Data Links
**********

.. default-role:: vhdl:entity

The Data Links section documents the high-speed serial link modules used in the chFPGA project for transmitting data between FPGAs and across backplanes.

- :doc:`XGLINK <xglink/index>`: 10 Gbps serial link modules using GTX transceivers on Kintex-7 FPGAs
- :doc:`XXVGLINK <xxvglink/index>`: 25 Gbps serial link modules using GTY transceivers on Ultrascale+ FPGAs
- :doc:`1G UDP/MAC <1G_UDP_MAC/index>`: 1 Gbps Ethernet UDP/IP/MAC modules for control and data communication
- :doc:`10G UDP/MAC <10GE_UDP_MAC/index>`: 10 Gbps Ethernet UDP/IP/MAC modules using GTX transceivers on Kintex-7 FPGAs
- :doc:`100G Ethernet <100GE_UDP_MAC/index>`: 100 Gbps Ethernet UDP/MAC modules using CMAC on Ultrascale+ FPGAs
