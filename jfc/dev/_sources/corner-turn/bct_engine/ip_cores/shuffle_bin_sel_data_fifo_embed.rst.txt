Shuffle Bin Selector Data FIFO (Embedded)
******************************************

Xilinx **FIFO Generator** IP core instance (embedded-memory-based) used in the shuffle bin selector stage of `bct_engine`. Buffers data words across the bin-selection pipeline. Embedded implementation chosen for lower latency and resource efficiency at smaller depths.
