Parameters
----------

- **PLATFORM_TYPE:** Platform type, defined as an enumerated type in :ref:`chfpga-package`. Is used to instantiate the platform-dependent XADC/SYSMON primitive.

Interface
---------

- ``s/m_axis_bsb_t*``: BSB bus interface to access the module's registers
- ``sysmon_clk``: System monitor clock. Clocks the SYSMON hardware block.
- ``sysmon_rst``: System monitor reset. Resets the SYSMON hardware block.

Implementation details
======================

Clocking
--------

Requires **stable SYSMON clock** (80 MHz max for the Virtex 6 series, 250 MHz max for the 7-Series and  UltraScale+). We use a 65.2 MHz clock generated by the system MMCM. 

Architecture
------------

We use an asynchronous FIFO to resynchronize the BSB bus to the SYSMON DRP clock domain in order to access its DRP registers through the `bsb_regs` module.
