Shuffle Bin Selector Flags FIFO
********************************

Xilinx **FIFO Generator** IP core instance (embedded-memory-based) used in the shuffle bin selector stage of `bct_engine`. Carries control and flag bits (valid, last, channel ID) alongside the data FIFO to maintain synchronous framing through the shuffle pipeline.
