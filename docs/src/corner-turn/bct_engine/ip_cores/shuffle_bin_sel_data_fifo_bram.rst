Shuffle Bin Selector Data FIFO (BRAM)
**************************************

Xilinx **FIFO Generator** IP core instance (BRAM-based) used in the shuffle bin selector stage of `bct_engine`. Buffers wide data words across the bin-selection pipeline. BRAM implementation chosen for larger depth requirements.
