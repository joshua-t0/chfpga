Introduction
============

Two versions of the correlator engine are present in this project.


- **CORR44**: BRAM-based correlator implementation for 7-Series FPGAs. See :doc:`corr44/index` for details.

- **UCORR44**: UltraRAM-based correlator implementation for Ultrascale+ FPGAs. See :doc:`ucorr44/index` for details.
