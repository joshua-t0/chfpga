Parameters
==========

- **TX_DATA_WIDTH:** Width of the data bus in bits (default: 64). Must match the GTY TX word width.

Interface
=========

- ``UNSCRAMBLED_DATA_IN``: Plain data word from the TX framing logic. The LSB is the first bit that will be transmitted serially.

- ``SCRAMBLED_DATA_OUT``: Scrambled output word forwarded to the GTY TX input.

- ``DATA_VALID_IN``: Asserted when ``UNSCRAMBLED_DATA_IN`` is valid and the LFSR state should advance.

- ``USER_CLK``: TX word clock (``tx_clk`` from `xxvglink_core`).

- ``SYSTEM_RESET``: Synchronous active-high reset; re-initializes the LFSR.

Implementation details
======================

Principle of operations
-----------------------

`xxvglink_scrambler` implements the **IEEE 802.3 64B/66B multiplicative (self-synchronizing) scrambler** originally generated by the Xilinx 7-Series Transceivers Wizard. Scrambling randomizes the serial bitstream to guarantee sufficient transitions for CDR and to reduce EMI.

The scrambler uses a 58-bit LFSR with the polynomial **x**\ :sup:`58` **+ x**\ :sup:`39` **+ 1** (feedback taps at bit positions 57 and 38, zero-indexed). For each input bit *i*, the scrambled output bit is ``unscrambled_in(i) XOR lfsr(38) XOR lfsr(57)``; the LFSR then shifts in that **scrambled** output bit (not the plain input). This multiplicative feedback is what makes the scheme self-synchronizing at the receiver: the descrambler reconstructs the identical LFSR sequence simply by feeding received bits back into its own LFSR. The implementation uses two concurrent processes: a combinatorial one that computes all ``TX_DATA_WIDTH`` output bits and the next LFSR state in parallel, and a registered one that latches the outputs on the rising edge of ``USER_CLK`` when ``DATA_VALID_IN`` is asserted. On reset, the LFSR is initialized to the alternating seed ``010101…01`` (58 bits) and the output is driven to zero.

Key Features
^^^^^^^^^^^^

- **Multiplicative self-synchronizing**: Feeds scrambled output back into the LFSR, enabling the receiver to lock automatically without extra control signals
- **Parallel processing**: Computes all ``TX_DATA_WIDTH`` scrambled bits combinatorially in a single clock cycle
- **Standard polynomial**: x\ :sup:`58` + x\ :sup:`39` + 1 as specified by IEEE 802.3 Clause 49

Usage in XXVGLINK
^^^^^^^^^^^^^^^^^

The scrambler is used in the :entity:`xxvglink_tx` module to scramble data before transmission over the GTY transceiver. The scrambled data helps ensure reliable clock recovery at the receiver and reduces EMI emissions.
