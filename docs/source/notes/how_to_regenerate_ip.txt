How to regenrerate FFT2
Add hdl/FFT2 folder as a user library path
Add IP - > User -> FFT2.0
On the IP customization page, click select IP destination. Select _cores/KC705
Set IP name to FFT2. 
Select global, clock Generate.
make sure Pro
This will create a _Cores/KC705/FFT2.xcix core container
