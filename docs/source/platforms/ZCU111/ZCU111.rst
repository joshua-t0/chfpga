ZCU111
******

Platform wrapper
================

`chFPGA` is implemented on the ZCU111 using the ``chfpga_zcu111`` platform wrapper. See :ref:`platform_wrappers` for more details.

Configurations
==============

Supported firmware configuration:

- ``chfpga_zcu111_ct_config``: 8-channel F-Engine, corner-turn, 100G offload; no correlator. See :ref:`config_param_reference` for full parameter descriptions.


``ct`` configuration (*chfpga_zcu111_ct_config.vhd*)
----------------------------------------------------

8-channel F-Engine, UCT corner-turn (single-board), and 100G Ethernet real-time data offload via UPACK+CGE. No on-board correlator; data is offloaded to an external X-Engine.

Configuration parameters
------------------------

- :ref:`CONFIG_CHAN_IMPLEMENT_FFT <config_chan_implement_fft>` — TRUE; F-Engine with FFT
- :ref:`CONFIG_CHAN_FFT_TYPE <config_chan_fft_type>` — CHORD; 14-bit, 16384 samples, 32+32 output
- :ref:`CONFIG_CHAN_CAPTURE_TYPE <config_chan_capture_type>` — UCAP; URAM-based centralized capture
- :ref:`CONFIG_CHAN_SCALER_USE_COMPLEX_GAINS <config_chan_scaler_use_complex_gains>` — FALSE
- :ref:`CONFIG_NUMBER_OF_CHANNELIZERS_WITH_FFT <config_number_of_channelizers_with_fft>` — 8
- :ref:`CONFIG_CT_TYPE <config_ct_type>` — UCT; CHORD-like format
- :ref:`CONFIG_CT_LEVEL <config_ct_level>` — 1; single-board, no backplane
- :ref:`CONFIG_CT_CLK_SOURCE <config_ct_clk_source>` — ADC_CLK; 400 MHz processing clock
- :ref:`CONFIG_CT_LANE_TO_LINK_MAP <config_ct_lane_to_link_map>` — (0 => -1); bypass lane
- :ref:`CONFIG_CORR_TYPE <config_corr_type>` — NONE; X-Engine off-board
- :ref:`CONFIG_CORR_READOUT_BINS <config_corr_readout_bins>` — (0 => 0); not used
- :ref:`CONFIG_DATA_LINK_TYPE <config_data_link_type>` — UPACK_CGE; 100G Ethernet offload
- :ref:`CONFIG_DATA_LINK_LINK_TO_QUAD_MAP <config_data_link_link_to_quad_map>` — (0 to 3 => 0); single quad
- :ref:`CONFIG_DATA_LINK_QUAD_TO_REFCLK_MAP <config_data_link_quad_to_refclk_map>` — (0 => 0); single refclk


Clocking
--------


Clock frequency selection
-------------------------


The ZCU111's LMK04208  programmable PLL provides only 2 clocks to the fabric, so we can't have a   reference clock (REFCLK, typically 10 MHz) that is separate from SYSREF (2.5 MHz if we want to support both 3000 and 3200 MSPS).

Furthermore, it does not look like we can do multiboard/multichip synchronization, as the SYNC input to the LMK04208 PLL is not connected, and the PLL does not have a SYSREF input.   We can only do multi-tile synchronization by syncing the PLLs and ADCs downstream of the LMK04208.

10 MHz is not a submultiple fo 3000/16 MHz, but it is for 3200/16 MHz. So 10 MHz can not be used to sync the ADCs sampling at 3000 MSPS.

We cannot use a REFCLK <10 MHz because the MMCM in the ``clocks`` module cannot accept an input less than 10 MHz.

Options:

- Stay at fs=3000 MSPS and REFCLK=10 MHz and don't support multi-tile ADC sync on ZCU111
- Use REFCLK=SYSREF=10 MHz  support MTS only for fs=3200 MSPS
