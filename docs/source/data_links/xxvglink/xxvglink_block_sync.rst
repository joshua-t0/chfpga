Principle of Operations
=======================

The `xxvglink_block_sync` module implements a state machine that performs block synchronization for 64B/66B encoded data. It searches for the synchronization header pattern in the incoming data stream and maintains synchronization once established.

The state machine handles:
- Initial synchronization acquisition
- Loss of synchronization detection
- Synchronization recovery

Key Features
------------

- **64B/66B block sync**: Implements block synchronization for 64B/66B encoding
- **State machine**: Uses a finite state machine to manage synchronization states
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XXVGLINK
-----------------

The block sync state machine is used in the :entity:`xxvglink_rx` module to establish and maintain synchronization with the incoming 64B/66B encoded data stream from the GTY transceiver.
