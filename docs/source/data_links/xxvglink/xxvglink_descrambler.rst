Parameters
==========

- **RX_DATA_WIDTH:** Width of the data bus in bits (default: 64). Must match the GTY word width.

Interface
=========

- ``scrambled_data_in``: Scrambled input data word from the GTY receiver.

- ``unscrambled_data_out``: Descrambled output data word delivered to the RX framing logic.

- ``data_valid_in``: Asserted when ``scrambled_data_in`` contains valid data (used to update the LFSR state).

- ``clk``: Word clock (synchronous to the GTY RX recovered clock).

- ``rst``: Synchronous active-high reset; initializes the LFSR to its seed value.

Implementation details
======================

Principle of operations
-----------------------

`xxvglink_descrambler` implements the **IEEE 802.3 64B/66B self-synchronizing descrambler** originally generated by the Xilinx 7-Series Transceivers Wizard. It reverses the scrambling applied by `xxvglink_scrambler` to recover the original payload.

The descrambler uses a 58-bit LFSR with the polynomial **x**\ :sup:`58` **+ x**\ :sup:`39` **+ 1** (feedback taps at bit positions 57 and 38). For each input bit *i*, the output bit is ``scrambled_data_in(i) XOR lfsr(38) XOR lfsr(57)``; the LFSR then shifts in ``scrambled_data_in(i)`` (not the output bit). Feeding the received scrambled bit — rather than the recovered bit — into the LFSR is the defining property of the self-synchronizing mode: the receiver's LFSR state tracks the transmitter's LFSR state automatically once data is flowing, without any out-of-band alignment signal. The implementation uses two concurrent processes: a purely combinatorial one that computes the XOR and the next LFSR state for all ``RX_DATA_WIDTH`` bits in parallel, and a registered one that latches the outputs on the rising edge of ``clk`` when ``data_valid_in`` is high. On reset, the LFSR is initialized to the alternating seed ``010101…01`` (58 bits).

Key Features
^^^^^^^^^^^^

- **Self-synchronizing**: Locks onto the transmitter's LFSR without extra handshaking by feeding the received (scrambled) bit into the LFSR
- **Parallel processing**: Full ``RX_DATA_WIDTH`` bits descrambled combinatorially in a single clock cycle
- **Standard polynomial**: x\ :sup:`58` + x\ :sup:`39` + 1 as specified by IEEE 802.3 Clause 49

Usage in XXVGLINK
^^^^^^^^^^^^^^^^^

The descrambler is used in the :entity:`xxvglink_rx` module to descramble received data from the GTY transceiver, recovering the original data that was scrambled by the transmitter.
