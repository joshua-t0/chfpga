Principle of Operations
=======================

The `xxvglink_scrambler` module implements a 64B/66B scrambler for the XXVGLINK system. Scrambling is used to ensure sufficient bit transitions in the serial data stream for reliable clock recovery and to reduce electromagnetic interference (EMI).

The scrambler uses a Linear Feedback Shift Register (LFSR) to generate a pseudo-random sequence that is XORed with the input data. The scrambling polynomial is defined by the 64B/66B encoding standard.

Key Features
------------

- **64B/66B encoding**: Implements the standard 64B/66B scrambling algorithm
- **LFSR-based**: Uses a Linear Feedback Shift Register for scrambling sequence generation
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XXVGLINK
-----------------

The scrambler is used in the :entity:`xxvglink_tx` module to scramble data before transmission over the GTY transceiver. The scrambled data helps ensure reliable clock recovery at the receiver and reduces EMI emissions.
