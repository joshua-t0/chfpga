Overview
========

64B/66B **scrambler** used on the **transmit** path of XGLINK. XORs payload with an LFSR sequence per the Ethernet-style 64B/66B rules to improve transition density and EMI. Typically instantiated inside `xglink_tx` ahead of the GTX gearbox.

.. autoentity:: xglink_scrambler

Principle of Operations
=======================

The `xglink_scrambler` module implements a 64B/66B scrambler for the XGLINK system. Scrambling is used to ensure sufficient bit transitions in the serial data stream for reliable clock recovery and to reduce electromagnetic interference (EMI).

The scrambler uses a Linear Feedback Shift Register (LFSR) to generate a pseudo-random sequence that is XORed with the input data. The scrambling polynomial is defined by the 64B/66B encoding standard.

Key Features
------------

- **64B/66B encoding**: Implements the standard 64B/66B scrambling algorithm
- **LFSR-based**: Uses a Linear Feedback Shift Register for scrambling sequence generation
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XGLINK
---------------

The scrambler sits in `xglink_tx` so data entering the GTX is scrambled before serialization. That helps **clock recovery** at the far end and reduces **EMI**.
