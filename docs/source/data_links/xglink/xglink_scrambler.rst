Overview
========

64B/66B **scrambler** used on the **transmit** path of XGLINK. XORs the payload with an LFSR sequence per the Ethernet-style 64B/66B rules to improve transition density and reduce EMI. Typically instantiated inside `xglink_tx` ahead of the GTX gearbox.

Entity documentation
--------------------

.. autoentity:: xglink_scrambler

Parameters
==========

- **TX_DATA_WIDTH:** Width of the data bus in bits. Default is 32. Must match the width used by the companion `xglink_descrambler` on the receive side.

Interface
=========

Data
----

- ``UNSCRAMBLED_DATA_IN``: Unscrambled input data (``TX_DATA_WIDTH`` bits). Bit 0 is the first bit to be transmitted (LSB-first convention).

- ``SCRAMBLED_DATA_OUT``: Scrambled output (``TX_DATA_WIDTH`` bits). Registered; valid one clock after ``DATA_VALID_IN`` is asserted.

Control
-------

- ``DATA_VALID_IN``: Data-valid enable. The LFSR state and the output register are only updated when this signal is ``'1'``, allowing the scrambler to pause between blocks without advancing its state.

Clock and reset
---------------

- ``USER_CLK``: Synchronous clock.

- ``SYSTEM_RESET``: Synchronous reset. Initialises the 58-bit LFSR to the all-alternating seed ``"0101…01"``.

Implementation details
======================

Principle of operations
-----------------------

The scrambler implements the self-synchronising LFSR defined by the 64B/66B standard (polynomial :math:`1 + x^{39} + x^{58}`). For each outgoing bit *i*, the scrambled output is:

.. math::

   s_i = d_i \oplus \text{LFSR}[38] \oplus \text{LFSR}[57]

The LFSR is then shifted left and fed with the *scrambled* bit :math:`s_i`. Because the shift register is driven by the output rather than the input, the receiver's self-synchronising descrambler can lock onto the sequence within 58 bits after a reset without any side-channel.

All ``TX_DATA_WIDTH`` bits are computed combinatorially in a single process and registered on the rising edge of ``USER_CLK`` when ``DATA_VALID_IN='1'``. The module is generated by the Xilinx 7-Series FPGAs Transceivers Wizard and sits in the TX datapath of `xglink_tx` ahead of the GTX gearbox interface.
