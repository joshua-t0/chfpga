Principle of Operations
=======================

The `xglink_gtx` module is a wrapper around the Xilinx GTXE2_CHANNEL primitive, which is the physical GTX transceiver on 7-Series FPGAs. It provides the interface between the XGLINK logic and the GTX transceiver hardware.

The wrapper handles:
- GTX transceiver configuration and control
- Clock domain crossing between user logic and GTX
- Reset sequencing
- Status monitoring

Key Features
------------

- **GTX wrapper**: Wraps the Xilinx GTXE2_CHANNEL primitive
- **10 Gbps operation**: Supports 10 Gbps serial data transmission
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XGLINK
---------------

The GTX wrapper is instantiated by the :entity:`xglink_core` module to provide the physical layer interface for 10 Gbps serial data transmission and reception.
