Entity documentation
--------------------

.. autoentity:: xglink_block_sync

Parameters
==========

- **SH_CNT_MAX:** Number of consecutive valid sync headers required to declare block synchronization achieved. Default is 64.

- **SH_INVALID_CNT_MAX:** Number of invalid sync headers within a window of ``SH_CNT_MAX`` that triggers loss of synchronization. Default is 16.

Interface
=========

Data input
----------

- ``RXHEADER_IN``: 3-bit sync header from the GTX gearbox. Bits [1:0] are checked: ``"01"`` indicates a data block; ``"10"`` indicates a control block. Any other pattern is treated as invalid.

- ``RXHEADERVALID_IN``: Header-valid strobe from the GTX gearbox. The state machine only evaluates ``RXHEADER_IN`` when this signal is ``'1'``.

Gearbox control
---------------

- ``RXGEARBOXSLIP_OUT``: Gearbox-slip command output. Pulsed for one clock cycle to advance the 66-bit alignment by one bit when the current header alignment is invalid.

Status
------

- ``BLOCKSYNC_OUT``: Block-synchronization achieved flag. Goes ``'1'`` once ``SH_CNT_MAX`` consecutive valid headers have been observed with fewer than ``SH_INVALID_CNT_MAX`` errors, and is cleared whenever realignment is needed.

Clock and reset
---------------

- ``USER_CLK``: Synchronous clock for the state machine.

- ``SYSTEM_RESET``: Synchronous reset; restarts synchronization acquisition from the beginning.

Implementation details
======================

Principle of operations
-----------------------

The state machine implements the IEEE 802.3ae / 64B/66B block-lock procedure. Starting from the ``BEGIN`` state it waits for the first ``RXHEADERVALID_IN`` pulse, then enters ``TEST_SH`` to count valid and invalid headers over a sliding window of ``SH_CNT_MAX`` samples.

If fewer than ``SH_INVALID_CNT_MAX`` invalid headers are seen, block sync is declared (``BLOCKSYNC_OUT='1'``). Once synchronization is lost (invalid-header threshold exceeded), the FSM pulses ``RXGEARBOXSLIP_OUT`` to shift the gearbox alignment by one bit and restarts the window. A 32-clock-cycle slip counter ensures the gearbox has settled before the next header evaluation begins.

The module is generated by the Xilinx 7-Series FPGAs Transceivers Wizard and used in `xglink_rx` to establish and maintain 64B/66B alignment on each GTX channel.
