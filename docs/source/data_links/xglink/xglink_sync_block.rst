Principle of Operations
=======================

The `xglink_sync_block` module implements a two-flip-flop synchronizer for clock domain crossing. It is used to safely transfer signals from one clock domain to another, minimizing the risk of metastability.

The synchronizer uses two flip-flops placed together in the same slice with RLOC constraints to minimize routing delay between them, which helps guard against metastability issues.

Key Features
------------

- **Two-flip-flop synchronizer**: Standard double-flop synchronizer design
- **RLOC constraints**: Flip-flops are placed together to minimize routing delay
- **Metastability protection**: Reduces risk of metastability in clock domain crossings
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XGLINK
---------------

The sync block is used throughout the XGLINK modules to synchronize control and status signals between different clock domains, particularly between the user clock domain and the GTX transceiver clock domains.
