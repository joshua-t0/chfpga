Principle of Operations
=======================

The `xglink_descrambler` module implements a 64B/66B descrambler for the XGLINK system. It reverses the scrambling operation performed by the transmitter to recover the original data.

The descrambler uses the same LFSR polynomial as the scrambler and XORs the received scrambled data to recover the original data stream.

Key Features
------------

- **64B/66B decoding**: Implements the standard 64B/66B descrambling algorithm
- **LFSR-based**: Uses a Linear Feedback Shift Register matching the scrambler
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XGLINK
---------------

The descrambler is used in the :entity:`xglink_rx` module to descramble received data from the GTX transceiver, recovering the original data that was scrambled by the transmitter.
