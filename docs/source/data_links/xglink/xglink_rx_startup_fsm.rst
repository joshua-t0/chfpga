Principle of Operations
=======================

The `xglink_rx_startup_fsm` module implements a finite state machine that performs RX reset and initialization sequences for the GTX transceiver. It manages the proper sequencing of reset signals and waits for the transceiver to be ready before allowing data reception.

The state machine handles:
- GTX RX reset sequencing
- Waiting for RX ready signals
- Error recovery
- Initialization completion

Key Features
------------

- **RX initialization**: Manages GTX receiver initialization sequence
- **State machine**: Uses a finite state machine for reset sequencing
- **Xilinx-generated**: Generated by Xilinx 7 Series FPGAs Transceivers Wizard

Usage in XGLINK
---------------

The RX startup FSM is used in the :entity:`xglink_rx` module to properly initialize the GTX receiver before data reception begins.
