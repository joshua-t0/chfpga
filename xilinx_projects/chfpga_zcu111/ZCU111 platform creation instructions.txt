Specify xsa from xilinx_projects/chfpga_zcu111/*.xsa

SHoult it have a embedded bitstream for XilFPGA and XilSecure to load properly?

Select platform.spr, On psu_cortex53_0->standalone->Board support package
Clock Modify BSP settings

Supported libraries, select:

libmetal
lwip211
xilfpga
xilsecure (needed for xilfpga)
xilskey (probably not needed)


On the left panel, select library and configure:

lwip211

	no_sys_no_timers -> false

	dhcp_options
		lwip_dhcp: True

	igmp_options: true


	ip options:

		mtu: 9000

	tcp_options:
		tcp_wnd: 16384

	temac_adapter_options:
		tcp_ip_rx_checksum*: true
		tcp_rx_checksum_offload*: true
		jumbo frames: True

system.mss:
	BEGIN LIBRARY
	 PARAMETER LIBRARY_NAME = lwip211
	 PARAMETER LIBRARY_VER = 1.5
	 PARAMETER PROC_INSTANCE = psu_cortexa53_0
	 PARAMETER igmp_options = true
	 PARAMETER lwip_dhcp = true
	 PARAMETER no_sys_no_timers = false
	 PARAMETER tcp_ip_rx_checksum_offload = true
	 PARAMETER tcp_ip_tx_checksum_offload = true
	 PARAMETER tcp_rx_checksum_offload = true
	 PARAMETER tcp_tx_checksum_offload = true
	 PARAMETER tcp_wnd = 16384
	END
